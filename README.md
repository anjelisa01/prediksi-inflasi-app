# Inflation Prediction App
Final Year College Project, a web-based inflation prediction tool powered by Multiple Linear Regression from scratch, built to provide accessible and interactive forecasting through a simple web interface.

# Overview
This project was developed as part of my final year undergraduate coursework. The task was to make and use machine learning algorithm from scratch (without library), basically an AI development and integration project, here i use linear regression to make prediction on inflation rate based on historical economic indicators, and delivered it using Streamlit as the UI and have a database that contains the dataset and admin data. The application was online in 2023 and fully accessible by anyone who has the streamlit link, currently is not online.  

Admin can logged in to manipulate the dataset, regular user can just visit the link and perform prediction (no need to login).  

This was developed in 2023 and I use no AI on development, there's a lot to improve but the application reach the intended goals.

## Features
- Inflation Forecasting using Multiple Linear Regression
- Minimal yet interactive Streamlit based web UI
- Authenticated CRUD access to manage dataset entries
- Backed by a persistent database 
- Ideal for educational use or as a lightweight forecasting tool
